# CivicAgent pitch cheat sheet

Opening: Citizens should not need to understand government bureaucracy to report a broken streetlight.

Architecture: The LLM proposes. The schema defines truth. The state machine controls safety. The citizen confirms submission.

Wow cues: the side panel fills as the citizen speaks; evidence carries provenance; a second issue switches schemas without restarting.

Limitations: Hyderabad locations, evidence, and receipts are synthetic demo adapters. Production integration requires approved municipal endpoints and authentication.

Fallback order: mock provider, typed location, attachment-only evidence, API backup client.
